# Luxor9 Day 1 — Cinematic Campaign

Master line: **EVERYTHING IS CONNECTED. EXCEPT THE WORK.**

Final format: 9:16, 35 seconds, 30 fps, H.264/AAC.

Stack:
- Blender: optional signal-tunnel / architectural 3D pass
- Remotion: deterministic timeline, typography and compositing
- FFmpeg: audio bed, encoding, QC and delivery master
- Figma: 9-shot editable storyboard
- Canva: social key visual / derivative campaign assets

Creative constraints: premium enterprise AI, black/graphite, warm ivory typography, restrained cyan signal, no robots, no glowing AI brains, no cyberpunk neon.
